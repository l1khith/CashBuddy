2. Privacy Policy & Prominent Disclosures

2.1 Local Processing Model

CashBuddy operates under a strict 100% Offline, Zero-Server Architecture. All financial records, parsing operations, machine learning models, and configurations reside exclusively on your physical device:

  • Local Encrypted Data: Transaction ledgers (amounts, merchants, timestamps, categories), custom category taxonomies, budget limits, and Naive Bayes token frequency models are stored locally inside a 256-bit AES SQLCipher encrypted database. Master encryption keys are protected using the Android Keystore.
  • Ephemeral In-Memory Notification Ingestion: When granted notification permission (BIND_NOTIFICATION_LISTENER_SERVICE), CashBuddy inspects incoming banking and payment alerts solely in volatile system memory (RAM). Non-financial notifications, personal messages, one-time passwords (OTPs), and promotional alerts are discarded immediately without being written to persistent storage or disk.
  • Instant On-Device Screenshot Processing: Shared payment screenshots are processed entirely on-device using local text recognition. The temporary image cache is deleted and unlinked immediately after text extraction.
  • Zero Data Transmission: The application does not declare or request the android.permission.INTERNET or android.permission.ACCESS_NETWORK_STATE permissions. No data physically leaves your device; there are zero network sockets, telemetry streams, or external servers.

2.2 Permissions Table & Prominent Disclosures

The App requests only permissions strictly required for local, on-device functionality. In accordance with Google Play Developer Policies, we provide the following prominent disclosures:

Permission Key Operational Purpose & Prominent Disclosure
BIND_NOTIFICATION_LISTENER_SERVICE Prominent Disclosure: Used exclusively to read incoming banking and UPI payment notifications locally in device RAM to automate expense logging without manual data entry. Notification data never leaves the device and is never written to remote storage.
USE_BIOMETRIC Enforces optional hardware-backed fingerprint or facial recognition (BIOMETRIC_STRONG) on app launch and upon returning from a 5-minute background inactivity interval.

2.3 Zero Advertising, Analytics & Third-Party SDKs

CashBuddy contains zero advertising SDKs, zero cloud telemetry or analytics libraries, and zero remote crash logging services. Any transitive background tracking or network helpers bundled with third-party libraries are explicitly stripped during compilation via Android Manifest merger removal rules.

2.4 User Sovereignty: Data Retention, Export & Deletion

Your financial data is completely under your custody. You can export your full transaction history at any time to standard RFC-4180 CSV format via Android's Storage Access Framework (SAF). Furthermore, you can permanently erase all recorded transactions and reset machine learning models directly within the application via Settings → Delete All Transactions and Settings → Reset Training Data. Uninstalling the App permanently deletes all local database records and hardware-bound encryption keys.
